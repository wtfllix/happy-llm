# 零基础伴读模式

伴读模式面向没有数学、机器学习或 NLP 专业背景，但希望继续阅读原教材并真正理解大模型的读者。

## 它会做什么

- 在容易卡住的位置补充直觉、生活类比和最低限度的前置知识。
- 明确告诉你“现在只需要记住什么”，避免在一个公式旁边展开另一门完整课程。
- 保留专业术语，并帮助你建立术语与直觉之间的联系。
- 所有伴读卡片都可以折叠，也可以在章节顶部统一隐藏。

## 它不会做什么

- 不修改、删减或重写原教材正文。
- 不用不严谨的说法替换原术语、公式和代码。
- 不承诺读完卡片就掌握全部数学细节；卡片的目标是让你能够继续读原文。

## 推荐读法

先读原文。遇到看不懂但又不确定是否必须立即补课的地方，再展开紧随其后的伴读卡片。看完“先记住”后回到原文继续向下读，等完整走过一章，再决定哪些知识值得深入补充。

## 内容如何维护

每章伴读内容独立保存在 `docs/companion/chapterN.json`。展示插件只在浏览器渲染完成后定位原文节点并插入卡片，因此 `docs/chapter1/` 至 `docs/chapter8/` 中的教材 Markdown 始终保持原样。

新增卡片时需要提供：

- `id`：本章内唯一标识。
- `afterHeading`：卡片所属小节的完整标题，用作稳定回退定位。
- `afterText`：希望卡片紧随其后的原文片段；原文有调整时可只更新这个字段。
- `title`、`lead`、`explain`、`points`、`remember`：伴读内容，其中后四项可按需省略。

伴读应短于它所解释的正文，优先回答“这段在做什么、为什么要做、现在最低限度要懂什么”。
